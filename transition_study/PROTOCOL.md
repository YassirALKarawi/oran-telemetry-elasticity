# Initial mechanism test

Written before running this experiment. Use all seeds 51000--51039. No outcome-based filtering or tuning. The model has three stateful services, two destinations and an eight-slot transition deadline. The current source serves all traffic until each service completes migration. Destination copy and subsequent live traffic compete for its ingress capacity. Migration also consumes a shared transfer link and temporary compute. State sizes, service CPU and traffic requirements vary using the generator in experiment.py.

Destination 0 is cheaper but has slower modeled copying and a smaller ingress budget. These fixed asymmetries intentionally create a mechanism test, not a representative O-RAN performance distribution. Source operation is more expensive than destination operation. All setup and cutover times are zero in this initial model. Copy rates are fixed rather than dynamically optimized. Service is assumed continuous under the capacity constraints, not measured at packet level. No radio allocation, actual SDN rule update, state consistency, or physical deployment is modeled.

The baseline finds the minimum steady-state destination cost, then finds the exact best transition for every tied placement. It is not handicapped by a poor transition ordering. The joint method enumerates every final placement and feasible migration start schedule. Both methods have identical full information and constraints. The objective charges source occupancy until completion and destination occupancy from copying start to the fixed twenty-slot lifetime. Both serve all three services or report infeasibility. No admission rejection is used to improve their score.

Report paired cost improvements over all paired feasible cases, strict improvement count, baseline-only transition infeasibility and total infeasibility. Joint optimization weakly dominates by feasible-set inclusion, so that fact alone is not a novel theorem or proof of a strong contribution. This test only quantifies whether transition-aware placement can matter under the stated assumptions. Independent verification must recompute resource occupancy and costs from every returned schedule.
